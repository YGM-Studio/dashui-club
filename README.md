# 大水肌薄社区

一个可以部署在阿里云、腾讯云 Linux 服务器上的健身打卡与心得交流网站。前端 React + TypeScript + Vite，后端 Node.js + Express，数据库 SQLite。暖白与松绿色响应式界面，手机底部导航、桌面侧边导航。

## 已实现

- 邮箱密码注册、登录、退出，scrypt 密码哈希，HttpOnly 会话 Cookie。
- 每人每天一条打卡，可补记过往日期、编辑、删除；训练 / 饮食 / 恢复 / 心得分类。
- 标题、心得、时长、可选体重、心情、一张照片。
- 默认仅自己可见，可以公开至社区，或将已公开内容收回为私密。
- 照片也经过权限检查，上传时解码、压缩并移除元数据；私密记录无法被别人查看、点赞、评论或导出。
- 社区分类筛选、关键词搜索、分页、点赞、评论。
- 个人记录、月度日历、连续天数、每周目标、活动和体重趋势、JSON 导出。
- 用户昵称、目标和每周打卡天数设置。
- Docker Compose + Caddy 自动 HTTPS、持久化卷、健康检查、在线一致性备份脚本。

## 本地运行

需要 Node.js 24 LTS、npm。

```bash
npm ci
npm run dev
```

浏览器打开 http://localhost:5173 。API 在 3001 端口。开发模式会自动创建明确标注的示例内容，在登录弹窗点击「体验示例账号」可以体验完整成长页。体验账号 `demo@dashui.local`，密码 `DashuiDemo2026!`。新注册用户从零记录开始。

开发数据保存在 `data/community.sqlite`，照片存放于同一数据库。数据库和依赖均不应加入 Git。开发示例开关为 `SEED_DEMO=true`，生产模式禁止注入示例账号。**不要将本地开发数据库上传到线上，线上使用全新的数据卷。**

不需要示例数据时，在一个空数据库上运行：

```bash
DB_PATH=data/clean.sqlite NODE_ENV=development node server/index.js
```

另开终端运行 `npm run dev:web`。

## 云服务器部署

见 [DEPLOY.md](./DEPLOY.md)。默认面向**一台服务器、一个应用实例**的朋友社区。SQLite 在这个范围内能简化运维。不要把多个应用副本挂到同一数据库文件；需要横向扩展时迁移 PostgreSQL 和对象存储。

## 目录

- `src/main.tsx`：页面与交互。
- `src/styles.css`：响应式视觉系统。
- `server/index.js`：认证、授权、验证和 API。
- `server/db.js`：表结构与统计；时间按 Asia/Shanghai 计算。
- `server/seed.js`：开发环境示例内容。
- `server/backup.js`：SQLite 在线一致性备份。
- `tests/api.test.js`：真实 HTTP 集成测试。
- `public/`：本地 SVG 品牌和哑铃插画，无外部图片或字体依赖。

## 当前边界

这是朋友社区第一版，不包含商城、补剂推荐、付费、私信、关注关系、训练处方或 AI 建议。每条记录最多一张 5MB 图片。JSON 导出包含个人资料和记录文本、数值，不包含图片二进制或评论；完整备份使用 `server/backup.js`。

邮箱目前作为登录标识，尚无邮箱验证、找回密码或邮件发送。也未实现管理员后台、举报审核或自动内容过滤。计划向公众开放注册前，应补齐账号恢复和社区治理流程；朋友内测可以先按部署文档限定访问范围。用户可删除自己的记录，当前没有自助注销整个账号。

应用没有上线到任何云账户；部署需要你自己的服务器、域名与 DNS。仓库提供代码和可执行配置，不包含服务器凭据。
